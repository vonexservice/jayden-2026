# SEO Baseline Audit

**Status:** Not yet audited end-to-end  
**Website:** https://www.jaystraxrentals.com/  
**Rule:** Research and report first. No live changes without approval.

## 1. Access and baseline data

- [ ] Confirm access to Google Search Console.
- [ ] Confirm access to GA4 or the site's booking/analytics reporting.
- [ ] Confirm access and current ownership of Google Business Profile.
- [ ] Export 3–16 months of Search Console clicks, impressions, CTR, and average position.
- [ ] Export landing-page sessions and available booking/inquiry events.
- [ ] Establish current booking and lead counts, if tracked.
- [ ] Record date range, data source, and limitations.

## 2. Technical SEO and indexation

- [ ] Check robots.txt and XML sitemap.
- [ ] Inspect index coverage and excluded URL reasons in Search Console.
- [ ] Inspect representative home, category, equipment, trailer, contact, and booking pages.
- [ ] Check canonical tags, redirect chains, broken links, 404s, and duplicate URLs.
- [ ] Check page rendering, mobile usability, and Core Web Vitals where data is available.
- [ ] Validate structured data where appropriate (Organization/LocalBusiness, Product or Service only when accurate and supported).
- [ ] Verify HTTPS and preferred host consistency.
- [ ] Separate actual defects from normal exclusions such as filtered, duplicate, or booking-system URLs.

## 3. On-page quality

- [ ] Inventory indexable URLs, titles, meta descriptions, H1s, canonical targets, and status codes.
- [ ] Find missing/duplicate titles and descriptions.
- [ ] Confirm each important page targets one clear primary intent.
- [ ] Improve descriptive product/equipment copy where thin or duplicated.
- [ ] Add useful links between equipment categories, individual rentals, delivery information, FAQs, and booking pages.
- [ ] Check image alt text, filenames, compression, and dimensions.
- [ ] Confirm rates, availability, rental duration, pickup/delivery terms, and restrictions are accurate.

## 4. Local SEO

- [ ] Verify Google Business Profile name, category, phone, website, hours, and service-area setup.
- [ ] Confirm address visibility follows the actual customer-facing/pickup model and Google's current guidelines.
- [ ] Compare business name, phone, website, and address/service details across important directories.
- [ ] Record existing listings before building new citations to avoid duplicates.
- [ ] Review recent customer feedback and develop a compliant review-request process.
- [ ] Compare local search competitors and their equipment/category coverage.
- [ ] Only target nearby locations where service and delivery are genuinely available.

## 5. Conversion path

- [ ] Test a rental inquiry on desktop and mobile without submitting a real order.
- [ ] Record clicks and steps from category page to rental detail to booking.
- [ ] Confirm phone, email, and contact CTAs work.
- [ ] Check whether availability, fees, deposits, delivery, taxes, and rental conditions are easy to understand.
- [ ] Identify friction, broken flows, and unnecessary steps.
- [ ] Verify analytics events before using them to judge performance.

## 6. Prioritization

Score each finding by:
- **Impact:** likely effect on qualified visibility or conversion.
- **Confidence:** strength of evidence.
- **Effort:** estimated time/risk.
- **Dependency:** access, vendor, or approval needed.

Recommended order: critical indexation/conversion failures; high-intent landing pages; booking friction; local profile accuracy; content gaps; authority-building opportunities.
