## Page-mapping rules

1. Map one primary intent to one strongest destination.
2. Check current URLs and rankings before creating new pages.
3. Prefer improving useful existing pages over duplicating them.
4. Use natural, specific titles and headings; avoid repetitive keyword stuffing.
5. Include current rental details and a clear path to check availability or book.
6. Add internal links from relevant category, guide, and FAQ content.
7. Track changes and compare performance after enough time has passed.

## Validation checklist

- [ ] Export query/page data from Search Console.
- [ ] Check search volume and competition with a trusted keyword source.
- [ ] Map existing URLs to target themes.
- [ ] Flag cannibalization and missing high-intent destinations.
- [ ] Prioritize by commercial intent, impressions/clicks, conversion value, and effort.
- [ ] Confirm each proposed page matches real inventory and service coverage.
